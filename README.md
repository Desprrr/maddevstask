# Монитор доступности сайтов

Тестовое задание "Agentic Developer" — Задание 3. Пользователь добавляет проверки сайтов
(URL, интервал, таймаут, ожидаемый код/строка), сервис регулярно их опрашивает, отслеживает
инциденты, шлёт оповещения на почту (в тестовом окружении — через заглушку) и показывает
живую панель статусов и публичную страницу статуса.

> Статус проекта: **в разработке**. Этот раздел будет обновлён полным честным описанием
> состояния (что работает, что нет, что не делали и почему) по мере продвижения — см. также
> [`DECISIONS.md`](./DECISIONS.md) для лога решений с таймштампами.

## Стек

- Backend: Python + FastAPI (asyncio), SQLAlchemy (async) + asyncpg, Alembic
- Frontend: Vue 3 + TypeScript + Vite
- СУБД: PostgreSQL
- Почта: заглушка (Mailpit в docker-compose, либо fake-outbox в БД для локальной разработки без Docker)
- Симулятор проверяемых сайтов: отдельный маленький сервис `target-emulator`

## Структура репозитория

```
backend/            FastAPI backend
target-emulator/    сервис-эмулятор проверяемых сайтов (для демонстрации/тестов)
frontend/           Vue 3 + TS фронтенд
docker-compose.yml  postgres + mailpit + backend + target-emulator + frontend
DECISIONS.md        лог решений с таймштампами
```
